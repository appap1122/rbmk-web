哪些是原作，哪些是二次创作

  • 继承自原作：多方块吊装屏、遥控器、开机动画、线圈与喷气背包等表现层元素。
  • 二次创作新增：RBMK / HBM 数据采集层、审计与报警体系、巡屏与聚合中控、真实版供电、历史黑匣子、剪辑式导出、密码与工牌权限体系。
  • 重置版：在原作素材与玩法之上，把渲染层彻底重写（零 TESR）。

Tag 与标签的对应关系

站点不对版本做人工归类，只按 Tag 和发行版标记自动判定。你把 Tag 起对，页面上的标签就对了。

判定条件页面显示说明
Tag 含 -beta测试版三条通道之一
Tag 含 -preview预览版三条通道之一
其余正式版默认通道
发行版标记为 prerelease至少算测试版与 Tag 不冲突
Tag / 标题含 hotfix、紧急修复紧急修复可与其他标签叠加
Tag / 标题含 major、重大更新重大更新可与其他标签叠加
Tag / 标题含 unstable、experimental、不稳定不稳定任何通道都能挂
