常见问题

安装、使用、多人联机、历史数据——高频问题一次答清。

Install

安装与版本

重置版和原版线怎么选？

想要倾斜吊装、延续老存档 → 原版线（jiezhirbmkmod）；想要更现代的渲染架构（零 TESR、静态网格、更好性能）→ 重置版（rbmkdisplay）。两者功能一致、物品同名，但存档不互通，只能二选一。

多人进服被标红拒绝？

网络协议要求两端版本完全一致（如 18.1 ≠ 18.0）。所有客户端与服务端统一升级到同一版本即可；升级前请备份存档并删光旧版 jar（同名残留会加载冲突）。

可以和 HBM 核技术什么版本一起用？

面向 Minecraft 1.12.2 · Forge 14.23.5.2860 的 HBM 核技术扩展生态开发，需搭配带 RBMK 多方块结构的 HBM 版本使用。三卷《持证必读》手册内页标注了适配细节。

升级后旧屏幕会丢历史吗？

不会。17.x 升到 18.1 时，旧屏沿用已记录的历史继续积累；数据落在游戏目录 rbmk_history/，随存档走。升级前备份存档是好习惯。

Usage

使用与画面

曲线导出里历史是空的？

18.1 起，曲线历史屏一放置就开始自动记录，不再要求有人看着屏并停在曲线页。若刚放置就导出，历史自然很短——挂机一段时间再导出即可。

真实版显示屏黑屏了，还写着字？

那是断电提示：「真实版曲线显示屏断电，无法记录」。真实版屏需要 HE 或 FE 任一供电（HE 优先）。恢复供电后画面自动恢复，历史原样保留——断电不会丢档也不会挤光曲线。

导出 MP4 需要装什么？

可选。安装 JavaCV/FFmpeg 依赖即可直接导出 .mp4；不装也不会崩——自动降级导出 PNG 帧序列 zip，用本地播放器合成即可。

屏放歪了 / 想换方向怎么办？

原版线用吊梁可重新吊装调角度；重置版屏体贴墙平贴安装，拆下重放即可换面。屏体是多方块结构，拆任意一块整板回收。

Admin

服务器管理员

怎么追溯谁按了 SCRAM？

开机 / 断电 / SCRAM / 密码握手全程写入 rbmk_audit.log，含时间、玩家、目标堆。审计文件在游戏（或服务端）根目录，可直接 grep。

历史数据能备份 / 迁移吗？

能。整目录拷贝 rbmk_history/ 即可备份迁移；按屏幕维度分文件，删单个文件只丢那一块屏的历史。

担心终端命令被滥用？

终端支持密码握手保护危险操作，宏指令需显式创建；所有命令执行都进审计日志。建议配合权限插件限制终端方块的交互。
