收录说明

这个站收什么、怎么提交、标签怎么打，都在这一页。

收录范围

只收 HBM 核技术生态里的 Minecraft 1.12.2 Forge 模组，且必须能在 GitHub 或 Gitee 找到公开仓库与发行版（Release）。不接受网盘直链、不接受需要登录才能下载的文件。

  • 必须有公开仓库（GitHub / Gitee 任一）
  • 必须有 Release 或 Tag，且能对应到具体版本
  • 必须声明依赖（是否要 HBM、是否要别的模组前置）
  • 必须能说明 modid，避免与已收录的撞名

怎么提交

在存放本模组的仓库开一个 Issue，标题用「收录申请：<模组名>」，正文按下面的模板填。也可以直接给作者发消息。

模板：模组名 / modid / 版本号 → 仓库地址 → 依赖关系 → 一句话简介 + 一张截图 → 授权声明（允许本站索引你的发行版）。

Tag 与标签的对应关系

站点不对版本做人工归类，只按 Tag 和发行版标记自动判定。你把 Tag 起对，页面上的标签就对了。

判定条件页面显示说明
Tag 含 -beta测试版三条通道之一
Tag 含 -preview预览版三条通道之一
其余正式版默认通道
发行版标记为 prerelease至少算测试版与 Tag 不冲突
Tag / 标题含 hotfix、紧急修复紧急修复可与其他标签叠加
Tag / 标题含 major、重大更新重大更新可与其他标签叠加
Tag / 标题含 unstable、experimental、不稳定不稳定任何通道都能挂

联系方式

有问题先看 百科页的 FAQ。要改收录信息、撤下某个版本，或者报下载死链，在仓库提 Issue 最快。

  • GitHub：appap1122/jiezhi-and-baldih-rbmk-monitor/issues
  • Gitee：gitee.com/baldih/jiezhi-and-baldih-rbmk-monitor/issues

文件策略

文件不转存。本站只是索引：下载按钮直连 GitHub / Gitee 的发行版附件，作者删了某个版本，按钮会跳回发布页。这里仅提供 public/downloads/ 一个口子，给作者手动补传上游缺失的包（由本地后台上传，优先级高于上游数据）。
