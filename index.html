安装

四步上车。

Minecraft 1.12.2 + Forge 14.23.5.2860（推荐最新版）。

放入 HBM

本模组是 HBM 核技术的监控外挂，需同时安装 Nuclear Tech Mod。

⚠️ 红线一：原版线与重置版不可同装（modid 不同能同时启动，但存档物品互不通用，混用后果自负）； 红线二：多人游戏所有客户端必须装同一版本（版本不一致会在握手阶段被拒，这是保护不是 bug）； 红线三：升级版本前备份存档，mods 里删光旧版 jar 只留新版。

常见问题

曲线导出里历史是空的？

18.1 起，曲线历史屏一放置就开始自动记录，不再要求有人看着屏并停在曲线页。若从 17.x 升级，旧屏会沿用它已记录的历史；新放置的屏从放置那一刻起积累。数据落在游戏目录 rbmk_history/。

真实版显示屏黑屏了，还写着字？

那是断电提示：「真实版曲线显示屏断电，无法记录」。真实版屏需要 HE 或 FE 任一供电（HE 优先）。恢复供电后画面自动恢复，历史原样保留——断电不会丢档也不会挤光曲线。

多人进服被标红拒绝？

网络协议要求两端版本完全一致（如 18.1 ≠ 18.0）。所有客户端与服务端统一升级到同一版本即可。

重置版和原版线怎么选？

想要倾斜吊装、延续老存档 → 原版线；想要更现代的渲染架构（零 TESR、静态网格、更好性能）→ 重置版。两者功能一致，物品同名但存档不互通，只能二选一。

导出 MP4 需要装什么？

可选。安装 JavaCV/FFmpeg 依赖即可直接导出 .mp4；不装也不会崩——自动降级导出 PNG 帧序列 zip。

终端命令速查

在落地终端 / 便携终端里使用，支持管道与宏。

⌨️ 基础命令

status输出全部已绑定反应堆的实时状态行
help列出命令与语法
scram <名>远程停堆指定反应堆（写入审计日志）
bind / unbind绑定 / 解绑数据源（bind x y z）
page <n>切换大屏页号（1 总览 / 2 热图 / 4 曲线）
passwd设置终端密码（握手保护）

⌨️ 管道与宏

| filterstatus | filter heat > 800，支持 > < >= <= = 与字段别名，结果 10 秒有效
macro setmacro set drill scram RBMK-1; status 保存命令序列（嵌套 ≤ 3）
macro runmacro run drill 执行已保存的宏
macro list列出全部宏定义
macro del删除指定宏
export配合剪辑 GUI 导出 PNG 序列 / CSV / MP4
