Features

功能特性

九大子系统，覆盖监控、供电、告警、记录与导出全链路。

📺

四页监控大屏

总览 / 热图 / 自定义 / 曲线四页屏，4×3 多方块吊装大板，768×576 高清动态画面，开机自检动画。

🔋

真实版 HE·FE 双源

_real 真实版显示屏独立 HE 缓冲，HE / FE 任一有电即可工作，屏上显示当前电源来源；断电黑屏提示、恢复自动续录。

🎮

遥控 SCRAM

手持遥控器对准屏右键即可远程停堆；报警灯塔随报警等级变色鸣响，中控室氛围拉满。

⌨️

终端与管道

落地终端 / 便携终端，status | filter heat > 800 管道过滤、宏指令、密码握手，落地终端大屏同步显示。

🗂️

历史黑匣子

曲线历史放置即自动记录（不依赖有人看屏），15 秒批量落盘 rbmk_history/，断电冻结不丢档，重启接续。

🎬

剪辑式导出

像剪映一样框选时间段：导出 PNG 序列 / CSV / MP4 视频（无依赖自动降级），导出 GUI 内播放预览。

🛡️

审计日志

开机 / 断电 / SCRAM / 密码握手全程写入 rbmk_audit.log，服务器管理员可追溯每一次操作。

🔄

轮播与巡屏

轮播屏自动轮翻总览 / 热图 / 曲线页；巡屏面板把全厂所有屏聚合到一个 GUI 里逐个查看。

📖

三卷手册

游戏内《持证必读》三卷手册，从放置接线到终端命令全教程，固件横幅与模组版本同步。

Screen Pages

屏页预览

四种屏页画面示意（游戏内为 768×576 实时动态画面）。

总览页

均温 / 通量 / 水 / 蒸汽四大仪表 + 燃料棒状态与氙毒累积。

热图页

每根燃料棒一格，色阶直读温度分布，过热棒一眼锁定。

曲线页

温度 / 通量实时曲线，断链离线留下真断口（不连线伪造），历史黑匣子可回放导出。

终端

落地终端 / 便携终端：管道过滤、宏指令、遥控 SCRAM，全程写入审计日志。

Terminal

终端命令速查

在落地终端 / 便携终端里使用，支持管道与宏。

基础命令

status输出全部已绑定反应堆的实时状态行
help列出命令与语法
scram <名>远程停堆指定反应堆（写入审计日志）
bind / unbind绑定 / 解绑数据源（bind x y z）
page <n>切换大屏页号（1 总览 / 2 热图 / 4 曲线）
passwd设置终端密码（握手保护）

管道与宏

| filterstatus | filter heat > 800，支持 > < >= <= = 与字段别名，结果 10 秒有效
macro setmacro set drill scram RBMK-1; status 保存命令序列（嵌套 ≤ 3）
macro runmacro run drill 执行已保存的宏
macro list列出全部宏定义
macro del删除指定宏
export配合剪辑 GUI 导出 PNG 序列 / CSV / MP4

FAQ

常见问题

曲线导出里历史是空的？

18.1 起，曲线历史屏一放置就开始自动记录，不再要求有人看着屏并停在曲线页。若从 17.x 升级，旧屏会沿用它已记录的历史；新放置的屏从放置那一刻起积累。数据落在游戏目录 rbmk_history/。

真实版显示屏黑屏了，还写着字？

那是断电提示：「真实版曲线显示屏断电，无法记录」。真实版屏需要 HE 或 FE 任一供电（HE 优先）。恢复供电后画面自动恢复，历史原样保留——断电不会丢档也不会挤光曲线。

多人进服被标红拒绝？

网络协议要求两端版本完全一致（如 18.1 ≠ 18.0）。所有客户端与服务端统一升级到同一版本即可。

重置版和原版线怎么选？

想要倾斜吊装、延续老存档 → 原版线；想要更现代的渲染架构（零 TESR、静态网格、更好性能）→ 重置版。两者功能一致，物品同名但存档不互通，只能二选一。

导出 MP4 需要装什么？

可选。安装 JavaCV/FFmpeg 依赖即可直接导出 .mp4；不装也不会崩——自动降级导出 PNG 帧序列 zip。
