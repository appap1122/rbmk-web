安装

本模组是 HBM 核技术（Nuclear Tech Mod） 的扩展，运行在 Minecraft 1.12.2 + Forge 14.23.5.2860（任意 14.23.x 均可）。

  1. 装好 Forge 1.12.2，启动一次游戏生成 .minecraft/mods。
  2. 把 RBMK-Monitor-版本.jar 丢进 mods/，不要解压。
  3. 装 HBM 核技术本体。没有它，屏幕能放能开，但会提示「数据源未绑定」。
  4. 启动，日志里出现 jiezhirbmkmod ... is loading. 即为加载成功。
两条产品线不能混装。原版线 modid 是 jiezhirbmkmod，重置版是 rbmkdisplay。两个 jar 同时放进 mods/ 不会崩，但会出现两套物品、两套方块，存档里的东西对不上号。

开机与绑定

最短路径

  1. 放下显示屏（4×3 多方块由吊装屏拼成，单块也能放）。
  2. 手持遥控器右键 RBMK 控制台，或任意 RBMK 部件（会在 24 格内自动找控制台）。
  3. 再右键屏幕 —— 绑定完成，屏幕开机自检。

开关机

右键屏幕切换 关机 → 待机 → 开机 → 待机；1.5 秒内点第二下直接跳到按第一下之前的状态推出来的目标（关机↔开机）。

设置中心

蹲下 + 连续右键两下打开设置中心：亮度 40–100、四种磷光主题、曲线对比模式（四通道叠加 + 可选对数纵轴）、运行报表一键生成（CSV / HTML）。

四页屏幕

四块屏共用同一套数据源，右键屏幕切页。绑定一个控制台，四块屏都能读到同一座堆芯。

屏内容适合放哪
总览平均柱温 / 最高柱温与熔毁阈值 / 温度变化率 / 中子通量 / 蒸汽量 / 燃料富集度 / 氙毒化 / 控制棒抽出率 + 熔毁风险盘 + 事件日志中控室主屏
热图15×15 柱阵热力图，按柱温离熔毁阈值上色，过热格描边值班台旁
自定义最多 8 条外部设备读数（储罐 / 电池 / 任意已记录设备）或 12 个自由摆放的仪表 / 曲线 / 文本块专门盯某几台设备
曲线并排三张折线图，热工组 / 燃料组自动轮换，纵轴自动量程，默认 60 秒窗口事故复盘、调参

热图页的读法和配色规则见 RBMK 监视器。

命令分两种：斜杠命令在聊天栏打（/rbmkcompat 这类），终端命令在落地终端 / 便携终端 / PDA 的界面里打（不带斜杠）。

阈值与自动化

终端支持「阈值监视链」：watch <metric> <op> <value> do scram|alarm|audit。规则落盘到 rbmk_watch.json，每 200 刻最多触发一次。

watch heat > 800 do scram # 超温自动停堆 watch water < 40 do alarm # 缺水拉响警报 watch flux > 2000 do audit # 只写审计，不动手
整套监视链走审批：开启需要全体管理员/房主在弹窗里全票通过，关闭任意一名管理员同意即生效。开启方式：双击操作员工牌。

倒计时与告警

  • 倒计时：曲线屏 / 终端可设倒计时，到点触发告警或停堆；倒计时期间屏幕顶部有黄字横幅。
  • 告警等级：预警（黄）/ 严重（橙）/ 熔毁（红）三级，越线整屏闪烁并拉响汽笛。严重档走 AMBIENT 声道，基地另一头也听得见。
  • 红石联动：九种触发条件（告警中 / 最高柱温 / 平均柱温 / 中子通量 / 温升速率 / 熔毁 / 信号丢失 / 自定义槽 1 / 关闭），带阈值与反相。
  • 告警扩音器：潜行右键屏绑定，玩家随身发声；L1 两声、L2 长鸣。

FAQ

屏幕一片空白 / 显示 NO LINK

没绑数据源，或者 HBM 没装。手持遥控器右键控制台，再右键屏幕。装完 HBM 后要重启游戏。

屏幕上数字不刷新

屏幕在「待机」状态。右键切到「开机」。真实版还要满足红石 ≥ 10 且 FE 有电。

多人服里别人看不到屏幕

两边版本必须一致。18.3 起对端没装本模组会放行（互相看不见而已），但装了不同版本会被握手拒绝 —— 用 /rbmkcompat 看原因。

装了两个版本线，物品全乱了

卸掉其中一个，重启游戏。存档里已放置的方块会变成「缺注册名」的紫黑方块，用创造模式替换掉。

崩服了怎么查

看 logs/latest.log 里 [jiezhirbmkmod] 开头的行。18.3 起所有网络包异常都会被替换成一条 warn 日志（包名 + 异常），不会再直接崩服。

历史曲线丢了

历史存在 <游戏目录>/rbmk_history/，按「维度_坐标」一屏一个文件。断电期间采样冻结但历史保留，不要手动删这个目录。
